Claude Code already runs shell commands, so it can drive the `smarteraui` CLI directly — the only setup is giving it enough context to reach for a real component instead of writing one from scratch.

## Prerequisites

- A project already scaffolded with `npx smarteraui@latest init` — Claude works best once `components.json` exists.
- Claude Code installed and authenticated (`claude` on your `PATH`).

## Start using Smartera UI with Claude

Describe what you're building in plain language and let Claude choose the components:

```text
Build a settings page with a page header, a tabbed navigation between
"General" and "Billing", and a form with labeled inputs. Use Smartera UI
components — check `npx smarteraui@latest search` for anything you're
not sure exists before writing custom markup.
```

Claude will typically run `smarteraui search` or `smarteraui list` to confirm component names, then `smarteraui add <name>` for each one it decides to use, and finally write the page around them.

## CLAUDE.md instructions

Add a short section to your project's `CLAUDE.md` so every session — not just the one where you type the prompt above — knows the convention:

```md
## UI components

This project uses Smartera UI (`@smarteraui/ui`). Before writing any new
UI markup:

1. Run `npx smarteraui@latest search "<what you need>"` to check whether
   a component or full-page example already covers it.
2. Install matches with `npx smarteraui@latest add <name>` rather than
   hand-rolling the equivalent markup.
3. Import installed components from `@/components/...` (or your
   project's configured alias in `components.json`) and follow their
   existing prop APIs — don't rename props to "clean them up".
4. Only write new markup for something the registry genuinely doesn't
   have, and keep it in the same style: Tailwind utility classes, no
   inline styles, React Aria for anything interactive.
```

With that in place, Claude reaches for `smarteraui add` before improvising markup even on prompts that don't mention the library by name.

## MCP integration

An MCP server that would let an assistant query the registry directly, instead of shelling out to
`npx` for each lookup, is planned but **not built** — see the [MCP page](/integrations/mcp) and the [roadmap](https://github.com/aymanshabaro/smarteraui/blob/main/ROADMAP.md). Until it
exists, the CLI is the supported path, and it is enough: Claude Code runs `smarteraui search` and
`smarteraui add` through its own shell tool.
